# 工序操作资格

工序能力独立于系统接口权限。管理者在“生产管理 → 工序管理”的“可操作人员”中继续为单个工序批量增加人员、单条或批量移除关系；“用户工序资格”入口按当前工厂选择用户，配置全部工序开关并查看保留的指定工序集合。

开启全部工序（ALL）后，该用户具备当前工厂全部适用且启用工序的操作资格，未来新增工序也自动适用，不生成逐工序关系。原有指定关系保留；关闭 ALL 后恢复按这些关系判断。ALL 期间仍可维护指定关系，但删除其中一条不表示从 ALL 排除该工序。没有 ALL 且没有有效指定工序时，无工序操作资格。

ALL 只替代具体工序关系匹配。普通报工仍需当前用户有效、具备系统报工权限，且目标节点属于 Execution 实际锁定路径；节点存在派工名单时必须在名单内，状态、数量、质量、来源和精度规则继续生效。管理员账号没有默认 ALL，须通过相同正式入口配置。不同工厂的开关和指定关系各自独立。

查询、开启与关闭分别使用现有工序能力 list、create、delete 权限。关闭前会确认恢复指定资格，失效账号的残留开关可由有关闭权限的管理者按用户编号回收。配置带并发版本；发生冲突须刷新后重试。保存后重新读取摘要，派工候选下次查询包含有效 ALL 用户；其他已打开报工页面可重新定位刷新，正式提交始终重新校验资格。


生产执行、领料及数量规则见[生产流程](production.md)。
