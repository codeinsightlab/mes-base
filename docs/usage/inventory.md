# 库存与单据审核

LOCAL仓库以正式库存动作和余额为权威。草稿、页面保存成功或外部接口接收成功，都不能直接代表库存已经生效。

## 单据生命周期

- 正式出入库单统一使用 `StockDocument` 主单与明细；生产领料通过 `MATERIAL_ISSUE` 类型识别。生产投入页负责BOM/路径及数量场景录入，保存得到统一 `documentId`，审核仍走独立命令。
- `documentId` 是单据主表身份，`lineId` 是明细主键，行号由 `lineNo` 表达。投入、撤销及库存动作关联统一单据身份；生产投入状态与单据状态分别表达，不以取消草稿代替已审核领料撤销。
- 普通管理页：新增主单、维护明细、保存草稿，再审核。
- 领料、生产入库、不良/报废入仓等业务入口可提供“新增并审核”便捷操作，编排同一套单据与审核用例。
- 审核通过后，在同一LOCAL事务校验来源、权限、版本、数量和幂等，记录审核身份并执行库存动作。
- 审核生效单据不能通过普通编辑改写库存事实；合法订正、作废或恢复按各自正式接口及留痕规则执行。

## 来源与数量

领料复用BOM、工单余额、材料基本单位、批次和可用库存校验；正常生产入库按Execution的累计可入量校验。不良/报废入仓关联有效申报及处置，不能凭手填单号或类型名称绕过来源。

同一Execution支持分批入库；每次审核重新检查累计剩余量，草稿不占作已生效入库。正常品和质量入库分别计量，审核后复用同一生产收尾规则。入报废品仓不代表已完成最终销毁或核销。

部分单据类型尚未接通正式来源，可以保留草稿但禁止审核；不以其他出入库类型代替缺失的采购、委外、退料或调拨来源链。

## LOCAL与ERP

工单、原材料仓与成品仓须符合持久化来源及当前模式。EXTERNAL库存镜像仅供参考，不能通过本地命令修改ERP权威库存；UNKNOWN保留原身份及冻结依据，交由授权人员核实。完整规则见[LOCAL/ERP边界](../architecture/local-erp-business-boundary.md)。

仓内后续流转属于仓储；生产退料和通用调拨的开放范围以实际正式入口为准，不因为已有仓库或单据名称就认为全流程已实现。
