# 产品范围与后续方向

Base MES优先服务中小型离散制造企业，以LOCAL单阶段生产为当前交付重点，支持基于BOM的工单多组件用料需求。功能与状态以当前代码及目标环境验收为准，不把测试库通过等同于首厂上线。

## 已有基础

- RuoYi来源的后台管理底座、账号权限、数据空间和独立业务库。
- 物料、版本化多阶BOM维护、工艺路线、工单和锁定实际路径。
- 单材料BOM领料、同批追加、报工、不良申报和正式入仓。
- 正式仓储草稿/审核、分批生产入库及入库后统一收尾。

## 近期完善

工单及原用料子表已支持关联确切BOM版本、默认版本预选、按产量和直接组件比例填充可增改明细及一次聚合保存；下一步专项审查多组件领料出库及独立产出批次。业务边界和当前实现缺口统一见[生产流程](usage/production.md#单阶段工单与用料)，不以工单多明细保存成功代表多组件已经可投产。

现场操作及恢复稳定性、生产退料与通用调拨、工作站和标签、交期/在制/质量/人员产量统计，以及安装升级、恢复演练和首厂验收继续按需求推进。

## 后续扩展

ERP正式库存业务、委外闭环、设备运维与采集、辅助排程和只读生产AI按真实需求推进。

多阶BOM维护不等于多材料或多阶投产。专门返工、独立放行和定时完结已退出当前方案；报废最终处置及关闭后完整晚质量业务后置。这里维护方向和产品边界，不保存个人任务交接、Agent回执或交付日期承诺。
